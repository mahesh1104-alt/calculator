# Simple Interest Calculator

A simple bash script that calculates simple interest given principal, annual rate of interest, and time period in years.

## Formula
$$\text{Simple Interest} = \frac{P \times T \times R}{100}$$

Where:
- **P** = Principal amount
- **T** = Time period in years
- **R** = Annual rate of interest

## Input
- `p`: Principal amount
- `t`: Time period in years
- `r`: Annual rate of interest

## Output
- `simple interest` = $(p \times t \times r) / 100$
